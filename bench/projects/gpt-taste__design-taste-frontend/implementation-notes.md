# Implementation Notes

This project follows the assigned local snapshots only:

- `bench/skills/gpt-taste/SKILL.md` shaped the high-variance direction: asymmetric heroes, wide H1 containers, inline image typography, dense but gapless bento grids, marquee proof, and real GSAP scroll behavior for scale/fade and card-stacking moments.
- `bench/skills/design-taste-frontend/SKILL.md` kept the work grounded: dependency checks, no purple/blue gradient defaults, no Inter assumption, mobile collapse for asymmetry, accessible focus states, tactile controls, bounded color use, and isolated client-side motion in `components/ScrollTheatre.tsx`.

Surface decisions:

- `/landing` uses Lumen Ledger's compliance brief as the exact product scope, with a first-viewport brand signal, proof band, product depth, and final conversion.
- `/dashboard` intentionally starts with the Harbor Desk working surface rather than a hero, with filters, route health, exception queues, driver status, depot capacity, and an inspector region.
- `/product` focuses on the Meridian Type 42 object, variants, materials, specs, accessories, and configuration choices without testimonial filler.
- `/suite`, `/suite/itineraries`, `/suite/notes`, and `/suite/account` share a Northstar Atlas navigation system while giving each page a distinct structure.

No image generation, browser automation, or dev server was used. Imagery is limited to stable `picsum.photos` placeholders and CSS/SVG-like construction.
