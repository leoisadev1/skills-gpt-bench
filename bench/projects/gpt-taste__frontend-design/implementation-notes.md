# Implementation Notes

This project uses only the assigned local skill snapshots:

- `bench/skills/gpt-taste/SKILL.md`
- `bench/skills/frontend-design/SKILL.md`

The `gpt-taste` snapshot shaped the wide editorial hero structure, the pre-flight RNG design plan, inline typography images, dense bento grids with `grid-auto-flow: dense`, large chapter spacing, GSAP-driven scroll reveals, image scale/fade motion, marquee proof strips, and strict avoidance of cheap meta labels. I used the combined benchmark prompt text as the deterministic basis for the selected direction: Editorial Split, Outfit, Inline Typography Images, Horizontal Accordions-inspired expandable panels, Infinite Marquee, Scrubbing Text Reveals, and Image Scale/Fade Scroll.

The `frontend-design` snapshot shaped the stronger point of view for each surface: Lumen Ledger uses a compliance ledger visual system rather than generic SaaS cards, Harbor Desk starts as a dense operational surface instead of a hero, Meridian Type 42 centers the tangible camera object and buyer comparison workflow, and Northstar Atlas keeps a cohesive research-travel identity while giving each suite page its own structure.

No image generation tools, browser automation, dev servers, global design skills, or external public-repo write actions were used.
